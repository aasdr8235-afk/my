# Mouhib Writeups

A bilingual technical publication covering cybersecurity, networking, privacy, and systems.

Articles are published with custom vector technical schematics, protocol walkthroughs, and bi-directional layout support (Arabic RTL and English LTR).

---

## Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm

### Installation

```bash
npm install
```

### Local Development

Start the local development server:

```bash
npm run dev
```

Visit `http://localhost:4321/` in your browser.

---

## Production Build

Compile the static site to the `dist/` directory:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

---

## Deployment

The static output in `dist/` is ready for direct deployment to **Cloudflare Pages** or any static hosting platform.

Refer to [DEPLOYMENT.md](DEPLOYMENT.md) for full deployment instructions and custom domain configuration.
